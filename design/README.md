# design — amd64 데스크탑의 설계

이 디렉터리는 **amd64 데스크탑 전용**이다. 파이 Zero 2 W 는 지금의 콘솔
셸을 그대로 쓰고 여기 있는 것을 하나도 실행하지 않는다. 그래서 512MB
보드를 배려한 축소판이 없고, 블러를 끄거나 애니메이션을 포기하는 분기도
없다.

---

## 무엇이 어디에 있는가

### `reference/` — 원래 있던 것

프로젝트 소유자가 만든 설계 문서와 목업. **손대지 않는다.**

| 파일 | 내용 |
|---|---|
| `shell-design-spec.md` | 셸 전체 설계 — 색, 타입 척도, 상단바, 퀵메뉴, 검색, 알림 |
| `apps-and-settings.md` | 앱 목록과 설정 전 항목, 구현 우선순위 |
| `task-manager-settings-mockup.html` | 작업 관리자와 설정 앱, 화면 서른 개 |
| `quickmenu_*.html`, `search_*.html`, 그 외 | 퀵메뉴·검색·상단바 상태별 목업 |

새 화면을 넣자고 남의 완성된 그림을 다시 그리는 것은, 한 섹션에 대한
검토를 나머지 전부에 대한 논쟁으로 바꾸는 방법이다. 그래서 설정 목업의
열여섯 화면은 여기서 **그대로 가져다 쓴다.**

### `gui/` — 이 브랜치가 더한 것

**디자인 시스템** — 명세서의 문장 아래에 있어야 할 것들.

| 파일 | 내용 |
|---|---|
| `lp-type.css` | 크기별 자간, 고정 폭 숫자, 그림자 세 겹, 헤어라인, 반투명 |
| `gen-springs.py` → `lp-motion.css` | 스프링 아홉 개. "몇 ms 에 얼마나 튀며"에서 상수를 역산 |
| `lp-spring.js` | 중단 가능한 스프링 적분기 |
| `gen-sounds.py` → `sounds/*.wav` | 시스템 소리 열 개, 합성해서 만든 것 |
| `lp-ui.css` | 컴포넌트 — 행, 스위치, 자물쇠, 버튼, 키캡, 대화상자, 위험 구역 |

**설정 앱** — 소유자가 요청한 새 화면들.

| 파일 | 내용 |
|---|---|
| `lp-core.js` | 화면들이 공유하는 상태. 입력 소스, 단축키, 권한 |
| `lp-static.js` | 권한 모델을 모르는 열여섯 화면에 자물쇠를 바깥에서 씌우는 것 |
| `panes/` | 새로 만든 여섯 화면의 마크업과 동작 |
| `assemble.py` | 위의 전부를 `settings.html` 하나로 조립 |
| `check.js` | 브라우저로 열어서 규칙이 지켜지는지 실제로 눌러 보는 것 |

**열어 보는 것 — 이 두 개가 결과물이다.**

| 파일 | 무엇 |
|---|---|
| `settings.html` | 설정 앱 전체. 관리자/표준 계정을 위에서 바꿔 가며 볼 수 있다 |
| `feel.html` | 모션·타이포·재질·소리를 눌러 보는 작업대 |

## 검증

`check.js` 는 목업을 진짜 브라우저에서 열어 규칙마다 한 줄씩 찍는다.
그림이 아니라 동작이 주제이기 때문이다 — English 키보드를 지우려 할 때
무슨 일이 일어나는지, 두 단축키가 같은 조합을 원할 때 어떻게 되는지,
표준 계정이 공장 초기화에 닿으면 무엇을 보는지는 **보아서는 알 수 없다.**

```
84 통과, 0 실패
```

무엇을 확인하는가:

- **규칙** — English 삭제 거부와 그 이유, 수식키 순서가 달라도 같은
  조합, 예약된 조합은 시스템이 잡고 있다는 답, 표준 계정은 관리자가
  넘겨주려 해도 공장 초기화에 닿지 못함
- **경로** — 언어 추가 대화상자를 열어 일본어를 넣고, 캡처 대화상자에
  **진짜 Ctrl+Alt+J 를 눌러** 단축키가 바뀌었는지 보고, 남이 쓰는
  Super+Q 를 눌러 거부가 「창 닫기」라고 이름을 대는지 보고, 공장
  초기화의 세 관문을 순서대로 통과한다
- **디자인 시스템** — 인라인 색 없음, 스타일시트에 없는 클래스 없음,
  스프링 아홉 개가 전부 해석되고 66개 요소가 그것으로 전환하며 **직접
  쓴 베지어가 하나도 없음**
- **화면 크기** — 1440·1280·1024·380px 어디서도 넘치는 요소 없음

규칙 검사와 경로 밟기는 다른 것을 잡는다. 화면은 파일 안의 모든 규칙을
만족하면서도 쓸 수 없을 수 있고, 그것은 써 봐야만 드러난다.

## 다시 만들기

```sh
cd design/gui
python3 gen-springs.py     # lp-motion.css
python3 gen-sounds.py      # sounds/*.wav
python3 assemble.py        # settings.html
node check.js              # 브라우저로 검증
```

`gen-springs.py` 는 스프링이 명세서의 시간 예산(대부분 150~250ms, 큰
동작 350ms)을 넘기면 경고를 찍는다. `check.js` 는 규칙마다 한 줄씩
찍으므로, 깨지면 무엇이 깨졌는지가 아니라 **어느 규칙이** 깨졌는지가
나온다.

## 이 브랜치가 답한 요구사항

소유자가 목업과 함께 요청한 것, 그리고 어디에서 답했는지.

| 요청 | 어디 |
|---|---|
| 한/영 전환을 **키보드 언어 추가/삭제**로 | `panes/s-kbd`, `input-sources.md` |
| **English 는 무조건 들어가 있어야 함** | `LP.canRemoveSource()`. 거부하고 이유를 말한다 |
| **키 지정** | `panes/s-keys` — 키 캡처, 충돌 감지, 예약 조합 거부 |
| 단축키·키보드·설정·웹 등 **초기화 메뉴** | `panes/s-reset` |
| **공장 초기화** | `panes/factory-zone` |
| 공장 초기화는 **관리자만** | `LP.can('factory')` 는 표준 계정에게 항상 false. 관리자도 위임할 수 없다 |
| 일반 계정은 **일부 설정/앱/기능 제한** | `panes/s-perm` — 설정 영역별, 기능별, 앱별 |
| **목업 보고 디자인** | 열여섯 화면을 그대로 가져오고, 여섯 개를 같은 언어로 더했다 |
| 폰트·모션·재질·소리를 **맥처럼** | `feel.md`, `feel.html` |

## 아직 화면일 뿐인 것

정직하게 말해 둘 것: **이 디렉터리에는 컴포지터가 없다.**

여기 있는 것은 설계와, 그 설계가 맞는지 눌러 볼 수 있는 목업이다.
실제로 화면에 무언가를 띄우려면 `shell-design-spec.md` §8 의 순서가
남아 있다 — tinywl 빌드, QEMU 에서 커서 움직이기, `foot` 하나 띄우기,
플랫폼 서비스(D-Bus, PipeWire, polkit), 상단바 뼈대.

소리가 스피커까지 가는 경로도 아직 없다. 커널에는 ALSA 가 들어 있고
유저랜드에는 오디오를 다루는 프로그램이 하나도 없다. `feel.md` §4-5 가
세 가지 길과 권장안을 적어 두었다.
