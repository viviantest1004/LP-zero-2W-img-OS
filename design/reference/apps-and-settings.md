# 앱 목록과 설정 전체 항목

셸 명세서(`shell-design-spec.md`)의 후속. 이 OS에 무엇이 들어가고, 각 앱이 어떻게 생겼고, 설정에 어떤 항목이 있는지.

---

## 1. 앱을 두 종류로 나눈다

이 구분이 이 문서 전체의 뼈대다.

| 종류 | 만드는 방식 | 이유 |
|---|---|---|
| **시스템 앱** | 직접 제작 | OS의 정체성을 만든다. 셸과 시각적으로 이어져야 한다 |
| **일반 앱** | `apt`로 가져옴 | 이미 잘 만들어져 있다. 다시 만들 이유가 없다 |

우분투도 GNOME 앱을 가져다 쓴다. 밑바닥부터 만드는 것은 시간 낭비이고, 차별화는 셸과 시스템 앱에서 나온다.

---

## 2. 시스템 앱 — 직접 만든다

### 2-1. 설정

**역할**: 모든 시스템 설정의 단일 창구

**화면 구성**
```
┌──────────┬────────────────────────┐
│ 사이드바  │  제목                   │
│ (158px)  │  부제 (현재 상태)        │
│          │  ─────────────────      │
│ 네트워크  │  행 목록                 │
│ 화면      │  행 목록                 │
│ 소리      │  ─────────────────      │
│ ...      │  행 목록                 │
└──────────┴────────────────────────┘
```

**디자인 원칙**
- 모든 항목이 같은 행 구조. 퀵메뉴와 시각적으로 이어진다
- 오른쪽 요소는 세 종류만: 토글 스위치 / 현재 값 / 하위 화면 화살표 `›`
- 설명이 **필요한 항목에만** 두 번째 줄. `Wi-Fi`에는 붙이지 않고 `전체 화면일 때 자동으로 켜기`에는 붙인다
- 부제에 현재 상태를 넣는다 (`배터리 38% · 1시간 24분 남음`)
- 검색으로 항목을 직접 찾을 수 있다 (상단바 검색에서도 잡힘)

---

### 2-2. 작업 관리자

**역할**: 무엇이 자원을 쓰는지 확인하고 정리

**탭 구성**: 앱 / 프로세스 / CPU / 메모리 / GPU / 드라이브 / 네트워크 / 배터리

**앱 탭과 프로세스 탭을 나눈 이유**
앱 탭은 창이 있는 프로그램만. 프로세스 탭은 전부. 대부분은 "브라우저가 느려졌다"를 확인하러 오지 `systemd`를 보러 오지 않는다.

**GPU와 전력 열을 기본 표시한다**
윈도우는 GPU 열을 따로 켜야 하고 리눅스 시스템 모니터에는 아예 없다. 요즘 브라우저는 GPU를 상시 쓰고, 노트북에서는 전력이 CPU%보다 중요한 지표다.

**숫자 옆에 해석을 붙인다**
- 남은 공간 15% 미만 → 앰버 경고
- `화면 밝기를 낮추면 약 40분을 더 쓸 수 있습니다`

숫자만 보여주면 그게 나쁜 상태인지 알 수 없다. 행동으로 이어지는 문장을 붙인다.

**각 탭의 내용**

| 탭 | 내용 |
|---|---|
| 앱 | 이름, CPU, 메모리, GPU, 전력. 창 개수 표시 |
| 프로세스 | 위 + 디스크. 정렬 탭(CPU순/메모리순/GPU순/전력순). 하위 프로세스 접기 |
| CPU | 60초 그래프, 코어별 막대, 프로세스·스레드 수, 가동 시간, 온도, 클럭, 캐시 |
| 메모리 | 60초 그래프, 앱/캐시/시스템/여유 구간 막대, 상위 사용 앱, 스왑 |
| GPU | 60초 그래프, VRAM, 인코더·디코더, 소비 전력, 사용 중인 프로세스, 드라이버 |
| 드라이브 | 읽기·쓰기 속도 그래프, 응답 시간, 용량 구간 막대, SMART 수명, 총 기록량 |
| 네트워크 | 받기·보내기 그래프, 신호 세기, 앱별 사용량, IP·게이트웨이·대역, 오늘 사용량 |
| 배터리 | 잔량, 남은 시간, 현재 소비 W, 수명 %, 3시간 잔량 그래프, 앱별 소비 전력, 충전 횟수 |

### 2-3. 소프트웨어 센터

**역할**: `apt` 그래픽 껍데기

**화면**: 검색 / 추천 / 설치됨 / 업데이트

**디자인 노트**
- 앱 카드에 용량과 설치 후 남는 공간을 같이 표시
- 설치 진행은 알림으로. 창을 닫아도 계속 진행됨
- 저장소(repo) 관리는 설정 쪽이 아니라 여기 하위 화면에

---

### 2-4. 터미널

**역할**: 이 OS의 뿌리

**직접 만들지 말고 `foot`을 쓴다.** Wayland 네이티브이고 1MB 미만이며 이미 빠르다. 대신 기본 설정을 이 OS 스타일로 맞춘다.

- 글꼴 D2Coding 14px
- 색 팔레트를 셸 디자인 토큰과 통일
- 배경 `#1a1a1a`, 전경 `#e8e8e8`
- 창 모서리 10px, 여백 12px

## 3. 일반 앱 — `apt`로 가져온다

### 3-1. 기본 탑재 (이미지에 포함)

| 앱 | 패키지 | 왜 기본인가 |
|---|---|---|
| 파일 관리자 | `nautilus` | 없으면 파일을 못 연다 |
| 웹 브라우저 | `firefox` | 없으면 아무것도 못 한다 |
| 텍스트 편집기 | `gnome-text-editor` | 설정 파일 수정 |
| 이미지 뷰어 | `loupe` | 파일 더블클릭이 동작해야 한다 |
| 문서 뷰어 | `evince` | PDF |
| 계산기 | `gnome-calculator` | 검색창 계산의 확장 |
| 압축 관리자 | `file-roller` | zip 더블클릭 |
| 미디어 플레이어 | `mpv` | 가볍고 코덱 내장 |
| 디스크 유틸리티 | `gnome-disk-utility` | 파티션, 포맷, SMART |
| 스크린샷 | 셸에 내장 | 별도 앱 불필요 |

**합계 용량 감각**: Firefox가 가장 크고(약 250MB), 나머지 전부 합쳐도 그보다 작다.

### 3-2. 기본 탑재하지 않음 (소프트웨어 센터에서)

| 앱 | 이유 |
|---|---|
| LibreOffice | 700MB 이상. 쓰는 사람만 설치 |
| Thunderbird | 요즘 웹메일을 쓴다 |
| 음악 플레이어 | mpv로 충분. 필요하면 설치 |
| 웹캠, 토렌트, 원격 데스크탑 | 소수만 쓴다 |
| 달력, 연락처, 지도, 날씨, 할 일 | 온라인 계정 연동이 전제. 없으면 빈 앱 |

**판단 기준**: `apt`가 들어 있으니 필요하면 설치하면 된다. 우분투가 오피스를 기본 탑재하는 것은 인터넷 없이 설치하는 사람을 배려한 것이고, 이 OS는 그럴 이유가 없다.

### 3-3. 파이(ARM) 버전에서 추가로 제외

램 512MB 제약. Firefox 대신 경량 브라우저, LibreOffice·Evince·Nautilus 제외. 터미널과 파일 관리자는 텍스트 기반으로 대체 가능.

## 4. 앱 공통 디자인 규칙

`apt`로 가져온 앱들이 제각각으로 보이지 않게 하는 장치.

### 4-1. 창

- 모서리 반경 10px
- 그림자 2겹: `0 1px 2px rgba(0,0,0,.08)` + `0 8px 24px rgba(0,0,0,.12)`
- 제목 표시줄에 앱 메뉴를 넣지 않는다 (맥의 상단 메뉴바를 쓰지 않으므로)
- 창 버튼은 오른쪽에 닫기 하나만 기본, 최소화·최대화는 설정에서 추가

### 4-2. GTK 테마로 강제하는 것

대부분의 앱이 GTK4를 쓰므로, 테마 하나로 상당 부분이 통일된다.

- 폰트: Pretendard 14px
- 강조색: 시스템 강조색을 따름
- 사이드바 폭 158px
- 목록 행 높이 36px
- 모서리 반경: 버튼·입력 6px, 카드 8px

### 4-3. 통일할 수 없는 것

Firefox와 LibreOffice는 자체 UI를 그리므로 완전히 맞출 수 없다. 여기에 시간을 쓰지 않는다. 시스템 앱과 GTK 앱이 일관되면 충분하다.

## 5. 설정 — 전체 항목

**★** = 1차 구현 필수

### 5-1. 네트워크 ★

**Wi-Fi**
- 켜기/끄기 ★
- 주변 네트워크 목록 (신호 세기, 잠금 여부) ★
- 연결 / 해제 / 비밀번호 입력 ★
- 저장된 네트워크 관리 (자동 연결, 삭제, 우선순위)
- 숨겨진 네트워크 수동 연결
- 핫스팟 만들기
- 연결 정보 (IP, 게이트웨이, DNS, MAC, 대역, 속도) ★
- 데이터 사용량 (오늘 / 이번 달)

**유선**
- 자동 연결 ★
- IPv4 / IPv6 수동 설정 (IP, 서브넷, 게이트웨이, DNS)
- MTU, MAC 주소 복제

**그 외**
- VPN 추가·편집 (WireGuard, OpenVPN)
- 프록시 (없음 / 수동 / 자동)
- 비행기 모드 ★

### 5-2. 블루투스
- 켜기/끄기 ★
- 기기 검색 및 페어링 ★
- 연결된 기기 목록, 배터리 잔량 ★
- 연결 해제 / 기기 삭제 ★
- 이 컴퓨터를 다른 기기에 보이게 하기

### 5-3. 화면 ★

- 해상도 ★
- 주사율 ★
- 배율 (100 / 125 / 150 / 200%, 분수 배율 허용 여부) ★
- 방향 (가로 / 세로 / 뒤집기)
- 밝기 슬라이더 ★
- 자동 밝기
- 야간 모드 (자동 일몰~일출 / 수동 시간, 색온도)
- 어두운 화면 (다크 모드) ★
- **다중 모니터** — 배치 드래그, 주 모니터 지정, 확장 / 미러링 / 단일 ★
- 색상 프로파일 (ICC)

### 5-4. 소리 ★

- 출력 볼륨 ★
- 출력 장치 선택 ★
- 좌우 밸런스
- 입력 볼륨, 입력 장치 ★
- **앱별 볼륨** ★
- 알림음 선택
- 볼륨 조절할 때 소리 내기
- 시스템 음소거 상태 표시

### 5-5. 알림 ★

- 알림 받기 ★
- 잠금 화면에 표시 ★
- 잠금 화면에서 내용 가리기 (보낸 사람만)
- **방해 금지** ★
  - 켜기/끄기 ★
  - 자동 예약 (요일별 시작·종료 시각)
  - 전체 화면일 때 자동으로 켜기
  - 예외 허용 앱
  - 방해 금지 중 알림: 쌓아 두기 / 버리기
- **앱별 설정** ★ — 앱마다 허용/차단, 소리, 팝업, 잠금 화면 표시, 미리보기
- 긴급 알림은 항상 통과 (배터리 부족, 디스크 부족) — 설정 불가, 안내만

### 5-6. 전원 ★

- 전원 모드 (절전 / 균형 / 성능) ★
- 화면 끄기 시간 — 배터리 / 전원 연결 각각 ★
- 절전 대기 진입 시간 — 배터리 / 전원 연결 각각 ★
- 덮개를 닫을 때 동작
- 전원 버튼을 누를 때 동작
- 배터리 잔량 % 표시 ★
- 배터리가 적을 때 알리기 (임계값)
- 배터리 정보 (수명, 충전 횟수, 설계 용량 대비)
- 충전 제한 (80%까지만 — 지원 기기)

### 5-7. 모양

- 배경 화면 ★ — 기본 제공 + 사용자 이미지
- 강조색 선택
- 아이콘 테마
- 커서 크기
- 창 버튼 배치 (최소화·최대화 표시 여부)
- 애니메이션 켜기/끄기 (파이에서는 기본 끔)

### 5-8. 작업공간

- 개수 (동적 / 고정) ★
- 최대 개수 — **20개 상한** ★
- 이름 붙이기
- 다중 모니터에서 작업공간 처리 방식
- 창 스냅 (화면 가장자리)

### 5-9. 키보드 ★

- **입력 소스** ★ — 한국어(두벌식), English(US), 추가·순서
- 입력 전환 키 (한/영 키 / Shift+Space) ★
- 키 반복 속도, 반복 시작 지연
- Compose 키
- **단축키 전체** ★
  - 검색 열기 `Ctrl+Space`
  - 작업공간 전환 `Super+1~9`
  - 창 전환 `Alt+Tab`
  - 화면 잠금 `Super+L`
  - 스크린샷 (전체 `Print` / 영역 `Shift+Print` / 창 `Alt+Print`)
  - 화면 녹화
  - 볼륨·밝기·미디어 키
  - 터미널 열기, 파일 관리자 열기
  - 창 닫기, 최대화, 반쪽 스냅
  - **사용자 지정 단축키 추가** ★

### 5-10. 마우스와 터치패드 ★

- 포인터 속도 ★
- 마우스 가속 켜기/끄기
- 주 버튼 좌/우
- 스크롤 방향 (자연스러운 스크롤)
- 터치패드: 활성화, 타이핑 중 비활성화, 탭 투 클릭, 두 손가락 스크롤, 제스처
- 테스트 영역

### 5-11. 개인 정보 ★

- 화면 잠금 시간 ★
- 카메라 접근 (앱별) ★
- 마이크 접근 (앱별) ★
- 위치 서비스
- 화면 공유 허용
- 최근 파일 기록 보관 기간
- 휴지통 자동 비우기 주기
- 임시 파일 자동 삭제
- 오류 보고 보내기
- 인터넷 연결 확인 요청 보내기

### 5-12. 사용자 ★

- 계정 목록, 추가 / 삭제
- 비밀번호 변경 ★
- 계정 유형 (표준 / 관리자)
- 프로필 사진
- 자동 로그인
- 지문 인증 (지원 기기)

### 5-13. 앱

- 설치된 앱 목록 ★
- 앱별 권한 (카메라, 마이크, 위치, 알림, 파일)
- **기본 앱** ★ — 웹 브라우저, 메일, 음악, 동영상, 사진, 문서
- 파일 형식별 연결 프로그램
- 시작 프로그램 (부팅 시 자동 실행) ★

### 5-14. 저장 공간

- 드라이브별 사용량 ★
- 용도별 분류 (시스템 / 사용자 파일 / 앱 / 여유)
- 큰 파일 찾기
- 휴지통 비우기 ★
- 캐시 정리
- 마운트된 장치 목록

### 5-15. 날짜와 시간 ★

- 자동 날짜·시간 (NTP) ★
- 시간대 (자동 / 수동) ★
- 12시간 / 24시간 형식 ★
- 상단바 표시 형식 (요일, 초, 날짜 포함 여부)

### 5-16. 지역과 언어 ★

- 시스템 언어 ★
- 형식 (날짜·숫자·통화 표기 국가)
- 설치된 언어 관리

### 5-17. 접근성

- 시각: 고대비, 큰 텍스트, 커서 크기, 화면 돋보기, 화면 낭독기, 색 반전
- 청각: 소리를 화면 깜박임으로
- 타이핑: 화상 키보드, 고정 키, 느린 키, 튕김 키
- 포인팅: 마우스 키, 호버 클릭, 이중 클릭 지연
- 애니메이션 줄이기

### 5-18. 프린터

- 프린터 추가 (네트워크·USB 자동 탐색)
- 인쇄 대기열, 작업 취소
- 기본 프린터
- 프린터 옵션 (용지, 양면, 해상도)

### 5-19. 정보 ★

- 기기 이름 (변경 가능) ★
- 하드웨어: CPU, 메모리, GPU, 저장 공간 ★
- 소프트웨어: OS 버전, 커널, 화면 서버 ★
- 업데이트 확인 ★
- 라이선스 정보

## 6. 구현 우선순위

**1차 (★ 항목만)** — 이것만 있어도 쓸 수 있다
네트워크, 화면, 소리, 알림, 전원, 키보드, 개인 정보, 사용자, 앱, 날짜와 시간, 지역과 언어, 정보

**2차**
블루투스, 모양, 작업공간, 마우스와 터치패드, 저장 공간

**3차**
접근성, 프린터, 색상 프로파일

**당분간 `gnome-control-center`를 그대로 쓰고 하나씩 자체 구현으로 교체하는 것도 방법이다.** 설정 앱을 처음부터 다 만들면 그것만 수개월이고, 그동안 다른 게 멈춘다.
