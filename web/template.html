먼저 파일이 온전한지 확인하세요.

sha256sum -c SHA256SUMS.txt

SD카드에 굽기 — /dev/sdX를 꼭 확인하세요. 틀리면 그 디스크가 사라집니다.

xz -d < @PI_NAME@ | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

가상머신 — 압축을 풀고 디스크로 붙인 뒤 UEFI 부팅으로 설정하세요. MBR 부트스트랩은 비어 있어서 legacy BIOS로는 뜨지 않습니다.

SSH — 비밀번호 로그인은 아예 컴파일하지 않았습니다. 카드의 첫 번째 파티션(FAT32, 어느 PC에서나 열립니다)의 authorized_keys에 공개키를 넣으세요. 사용자는 root 하나입니다.

쓰기 전에 알아둘 것

지원되는 제품이 아니라 취미로 만든 운영체제입니다. 보안팀도, CVE 절차도, 대기하는 사람도 없습니다. 계속 돌아가야만 하는 일에는 Raspberry Pi OS Lite나 데비안을 쓰세요.
  • 실기기 검증이 아직입니다. 전부 QEMU에서 시험했습니다. 라즈베리파이 실물에서의 WiFi, 온도 센서, 하드웨어 워치독은 확인하지 못했습니다.
  • 보안 부분은 외부 감사를 받지 않았습니다. 업데이트 서명 검증, 방화벽, DNS·NTP 위조 방지가 구현돼 있지만 다른 사람이 검토한 적은 없습니다.
  • 재부팅을 넘겨 남는 곳은 /data 하나이고, 그건 카드 한 장의 파티션 하나입니다. 아까운 것은 따로 받아두세요.
  • GUI 없음, 패키지 적음, 컨테이너 안 됨.

확인된 것: amd64 이미지가 QEMU 실제 부팅에서 셀프테스트 51개 검사를 전부 통과합니다.

English

A Linux distribution written from scratch — kernel configuration, C library, init, shell and 107 commands, all of it written by Claude Code. The whole system is one file, 11–23MB.

Which image: the first is a Raspberry Pi Zero 2 W image that also runs in arm64 virtual machines; the second is for ordinary PCs and desktop VMs; the third is arm64 VMs only, and will not boot on the board.

Check what you downloaded with sha256sum -c SHA256SUMS.txt. Burn a card with xz -d < image.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync, checking /dev/sdX twice — that is the one mistake here a reboot cannot undo. In a VM, set UEFI boot; the MBR bootstrap is empty on purpose.

SSH has no passwords — password authentication is not compiled in. Put your public key in authorized_keys on the card's first partition, which is FAT32 and opens on any PC. There is one user, root.

This is a hobby operating system, not a supported product. No security team, no CVE process, nobody on call. Real Pi hardware is not verified — everything was tested in QEMU. The security work has not been audited. For anything that has to keep working, use Raspberry Pi OS Lite or Debian.

What is verified: the amd64 image passes all 51 checks in the project's self-test on real QEMU boots. Full source, in English and Korean, at @REPO_SHORT@. MIT licensed.
